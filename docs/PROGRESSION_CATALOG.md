# Permanent progression catalog — v0.5.0

Generated by `scripts/progression_catalog.py` from shipped definitions. Every talent rank costs one class talent point. Class levels are independent of run levels; XP required to advance class level L is 120 × L, preserving existing XP totals. Level 1 grants zero points; each later level grants one, capped at class level 100. Each 18-node tree has 40 allocatable ranks across four tiers, a central prerequisite path, side branches and one final capstone. Data defines each node's class, original-art icon, normalized position and cumulative rank effects.

## Shared gold upgrades

Bonuses combine with class talents in a snapshot when a run starts; mid-run purchases are blocked. Costs below buy the next rank, never all ranks together. Armor including live defenses retains its 75% mitigation cap. Health percentages apply to base class health; in-run health ranks still add 20 flat health. Gold gain multiplies ordinary run earnings, including victory bonuses, but not one-time achievement gold.

| Gathering (`magnet`) | 5 | 55, 110, 165, 220, 275 | Pickup range +12 units per rank | 0 shared ranks |
| Insight (`xp`) | 5 | 100, 200, 300, 400, 500 | Run gem XP +4% per rank | 0 shared ranks |
| Prosperity (`greed`) | 5 | 110, 220, 330, 440, 550 | Run gold rewards +4% per rank; achievement gold unchanged | 0 shared ranks |
| Recovery (`regen`) | 5 | 90, 180, 270, 360, 450 | Regenerate 0.1 health/sec per rank | 0 shared ranks |
| Second Thoughts (`rerolls`) | 3 | 180, 360, 540 | One additional card reroll each run per rank (R / X) | 0 shared ranks |
| Wisdom (`choices`) | 1 | 450 | Permanent fourth level-up card; requires eight shared ranks | 8 shared ranks |

Wisdom permanently unlocks four normal level-up cards after eight shared ranks and its 450-gold purchase. Elite chests retain three choices and guarantee an eligible evolution. Second Thoughts grants 1–3 rerolls per run; use R / controller X or the button. Each successful reroll spends one charge and keeps gameplay paused. Chests cannot be rerolled. Exhausted pools retain repeatable healing, gold, temporary power and (for four cards) a shield reward.

## Respecialization and starting equipment

Reset cost is **50 + 5 × allocated points** gold. It refunds every allocated point, preserves class XP/level and clears the chosen extra starting ability. The UI displays the exact cost and refund before confirmation. Insufficient funds or save failure leave the profile intact.

New characters have exactly one Rank 1 signature ability. Earning class XP alone grants no equipment. The preparation talent requires class level 15, at least 15 points already allocated and its previous-branch prerequisite. Buying it grants a choice screen; it equips nothing automatically. Select one of two optional extra Rank 1 abilities or select none. Hunter/Warlock companions require this advanced talent plus explicitly selecting Beast Companion/Summon Imp. The extra ability occupies a regular one-of-eight slot. Respec removes eligibility and selection. Spell-specific talent modifiers continue on evolved versions through their base ability IDs.
